# Plan: CellBiochemistry Enhancement Module

## Goal
Add a deep cellular biochemistry module — protein folding, membrane lipid dynamics, concentration gradients, active/passive transport, Michaelis-Menten enzyme kinetics, nucleotide-DNA coupling — opt-in via `WorldConfig.cellBio`, mirrored 1:1 TS↔Rust, with full test coverage.

## Architecture Constraints
- **Legacy bit-identical**: `cellBio` defaults OFF → all existing tests pass without modification.
- **Determinism sacred**: same seed+config → identical trajectory.
- **Parity**: TS and WASM must match.
- **All new code goes behind a flag gate** — no modification to `tickAgentChemistry` or `tickCell`.

### New Module: `cellbio.ts` / `cellbio.rs`

**`apps/simulation/src/cellbio.ts`** (~350 lines)

Types:
```ts
export interface CellBioState {
  proteome: Float32Array;     // length PROTEOME_SIZE — foldQuality per protein class [0..1]
  misfoldStress: number;      // accumulated misfolded protein burden [0..inf)
  gradient: Float32Array;     // length MOLECULE_COUNT — membrane-surface molecule concentration
}

export interface CellBioConfig {
  enabled: boolean;
}

export interface ApplyEnv {
  O2Local: number;
  mineralLocal: number;
  toxinLocal: number;
  pHLocal: number;
  waterAvailable: number;
}
```

Functions:
1. `createCellBioState(genome: Float32Array, chem: AgentChemistry): CellBioState` — proteome seeded from genome[184..188], gradient initialized from bulk molecule concentrations.
2. `tickFolding(chem, cell, bio, dt): { atpCost, foldEffect, misfoldDamage }` — chaperone-driven folding, pH/thermal stress, S-dependence, misfold accumulation → membrane damage.
3. `tickMembraneBiochemistry(cell, bio, chem, memGenes, externalMols, dt): { atpCost, membraneDelta }` — lipid repair, passive diffusion (permeability), active ion pump (ATP cost), endocytosis (RNG gated).
4. `tickGradientFlux(bio, chem, cellGenes, dt): void` — cytoskeletal transport between bulk molecules and gradient array.
5. `michaelisMentenRate(Vmax, substrate, productConc): number` — `Vmax * S/(Km+S) * 1/(1 + inhibition * P)`.
6. `applyCellBioTick(chem, cell, bio, env, memGenes, cellGenes, diet, catalysisGene, toxGene, ionGene, redoxGene, stoich, dt): { atpCost, membraneDamage, foldEffect }` — orchestrator: calls folding → gradient → membrane → MM adjustments on enzyme reactions.

**`crates/simulation/src/cellbio.rs`** (~380 lines)

Exact Rust mirror of `cellbio.ts`. `CellBioState` uses `Vec<f32>` for proteome and gradient. All function signatures and formulas match 1:1.

3. `cellbio.ts` — new file, pure functions, no engine wiring yet.
4. `cellbio.rs` — Rust mirror.
5. Rust `cells.rs` transport function port.
6. Engine wiring (TS + Rust) — behind `cellBio` flag.
7. Shared test file.
8. TS cellbio unit tests.
9. Rust cellbio unit tests.
10. Parity + divergence tests.
11. Full gate: cargo test → wasm-pack → sync → typecheck → npm test → e2e.
