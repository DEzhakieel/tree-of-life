# Results

Measurements produced by the research lab. Every number below is regenerated by
a CLI in `apps/simulation/src/research/` (npm scripts `research:*`) and written
to `apps/simulation/research/output/` with plots in `.../plots/`. The full
narrative is `apps/simulation/research/UNIFIED_RECORD.md`.

## 1. Scope ledger (v1.0.0, 2026‑10‑16)

A pre‑registered set of claims was tested statistically (effect sizes, t‑/χ²
tests where applicable, Bayes factors, Clopper–Pearson intervals).

| Outcome | Count |
|---|---|
| **Supported** | 23 |
| **Refuted** | 2 |
| **Inconclusive** | 9 |
| **Total claims** | 34 |

Refuted:

- **C‑AI‑03** — the LLM‑driven steerer performed **worse than the control**
  (do‑nothing) policy; the AI proposer is kept for *hypothesis generation*, not
  online control.
- **C‑SIG‑01** — the costly‑signalling prediction did not hold in the tested
  regime.

Reproduce: `npm run research:scope` (from `apps/simulation`). Ledger:
`research/output/scope.*`.

## 5. Determinism & cross‑engine parity

The experiment runner verifies reproducibility by re‑running and comparing
binary digests:

```
$ npm run research:experiment -- --verify
REPRODUCED: all digests bit-identical
```

This is the strongest result in the project: **a world is fully determined by
its seed**, and the TypeScript and Rust engines agree.

## Caveats

- The omics/quantum layers (E–J) are **readings of shared pools**; the TS
  reference reports zeros there by design. Treat their numbers as WASM‑only.
- "Supported" is statistical, not proof; see the per‑claim intervals in the
  ledger.
- The two refutations are reported rather than hidden — that is the point of a
  pre‑registered ledger.
